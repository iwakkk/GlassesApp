# Glasses App 👓✨

An iOS application built with SwiftUI to explore Apple technologies through an interactive glasses experience.  
This project focuses on implementing modern Apple frameworks such as Augmented Reality, SceneKit, CoreML, and RealityKit to create immersive and innovative user experiences.

---

## 📱 Features

- Modern SwiftUI interface
- Augmented Reality (AR) experience
- Real-time object visualization
- Interactive 3D glasses display
- Smooth and responsive UI
- Native iOS experience

---

## 🛠️ Technologies Used

- Swift
- SwiftUI
- ARKit
- RealityKit
- SceneKit
- CoreML
- Xcode

---

## 🚀 Getting Started

### Requirements

- macOS
- Xcode 15+
- iOS 17+
- Physical iPhone device recommended for AR features

### Installation

1. Clone this repository

```bash
git clone https://github.com/iwakkk/GlassesApp.git
```

2. Open the project in Xcode

```bash
cd GlassesApp
open GlassesApp.xcodeproj
```

3. Run the app on Simulator or your iPhone

> Some AR features may require a real device.
