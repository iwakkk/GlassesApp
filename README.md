# Glasses App 👓✨

An iOS application built with SwiftUI to explore Apple technologies through an interactive glasses experience.  
This project focuses on implementing modern Apple frameworks such as Augmented Reality, SceneKit, CoreML, and RealityKit to create immersive and innovative user experiences.

---

## ⚙️ How It Works

1. Users scan their face using the device camera.
2. The app analyzes the face shape using CoreML.
3. Based on the detected face shape, the application provides suitable glasses recommendations.
4. Users can select recommended glasses models directly from the app.
5. Using Augmented Reality, users can virtually try on the glasses in real time through the camera.
6. SceneKit and RealityKit are used to render and display interactive 3D glasses models for an immersive AR experience.

## 🚀 Getting Started

### Requirements

- macOS
- Xcode 15+
- iOS 17+
- Physical iPhone device recommended for AR features

### Installation

1. Clone this repository

```bash
git clone https://github.com/iwakkk/GlassesApp.git
```

2. Open the project in Xcode

```bash
cd GlassesApp
open GlassesApp.xcodeproj
```

3. Run the app on Simulator or your iPhone

> Some AR features may require a real device.
